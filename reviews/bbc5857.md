## Other observations

- PDEStudio's load-time Core check is minimal, but newer Core API use is guarded and compat pins Core 0.5 (both).
- Speed: `_template_data` loads a full dataset for its domain 2-3× per Run; `_update_entries!` rewrites the whole file; passes 2-3 of `run_all_simulations` are serial with `parallel = true` (B).
- `is_reference_method` silently treats e.g. `:upwind_exact_flux` as a reference when it shares the solver (B).
- CSV export writes only active methods (A). The animation Timer can drop interleaved user actions via `@with_lock` (A).
- Missing tests: one per finding above, notably method-less configs, reference-first methods, restricted name lookup, CSV round trip of `""`/`missing`/small ints, `calculate_all_stats!` on unsaved data.
