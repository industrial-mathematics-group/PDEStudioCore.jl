PDEStudioCore.Examples — Module
PDEStudioCore.Examples

Ready-made simulations: each test_*() returns a SimulationConfig that runs as it is, e.g. run_all_simulations(test_heat_1d()) or, in PDEStudio, set_sim_config!(test_heat_1d()).

The solvers are ordinary functions of the run's parameters (solve_*, exact_* for the references), written to be read: copy one as the starting point of your own. Configurations refer to them by name; names that are not found in the target module (set_target_module!) are looked up here, so a function of your own with the same name takes precedence.

source

Every example runs as it is:

using PDEStudioCore
set_stat_preset!("hyperbolic")
set_save_path!("results")
run_all_simulations(test_poisson_2d(); parallel = true, calculate_stats = true)

or, in PDEStudio, set_sim_config!(test_poisson_2d()) (for test_particles_2d, set_mode!(:lagrangian) first). The solvers are in src/Examples/, one file per example.

Solvers and exact solutions

PDEStudioCore.Examples.solve_advection_1d — Function
solve_advection_1d(params) -> ESimData

Linear advection $u_t + c\,u_x = 0$ on the periodic interval $[0, 1)$ with $u(x, 0) = \sin(2\pi x)$, N cells, end time T, time step from the CFL number cfl and the scheme :scheme:

  • "upwind": first order, $u_i - \nu (u_i - u_{i-1})$ (for $c > 0$), smears the wave;
  • "lax_friedrichs": first order, central, even more diffusive;
  • "lax_wendroff": second order, dispersive (the wave lags behind).
source
PDEStudioCore.Examples.exact_advection_1d — Function
exact_advection_1d(params)

The exact solution of solve_advection_1d: $u(x, t) = \sin(2\pi (x - c\,t))$.

source
PDEStudioCore.Examples.solve_burgers_1d — Function
solve_burgers_1d(params) -> ESimData

Inviscid Burgers $u_t + (u^2/2)_x = 0$ on the periodic interval $[0, 1)$ with $u(x, 0) = 1 + \frac12 \sin(2\pi x)$: the wave steepens and a shock forms at $t = 1/\pi$. N cells, end time T, time step from cfl, scheme :scheme:

  • "lax_friedrichs": conservative, first order, diffusive;
  • "godunov": conservative, first order, with the exact Riemann flux (sharp shock);
  • "nonconservative_upwind": upwind for $u_t + u\,u_x = 0$. Consistent, but not conservative: the mass drifts from the start (about 7 % by $t = 0.8$ at $N = 50$) and the shock moves at the wrong speed. Only conservative schemes converge to the right weak solution.
source
PDEStudioCore.Examples.solve_heat_1d — Function
solve_heat_1d(params) -> ESimData

The heat equation $u_t = \kappa\,u_{xx}$ on $[0, 1]$ with $u = 0$ at both ends and $u(x, 0) = \sin(\pi x) + \frac12 \sin(3\pi x)$, N intervals, end time T and the time step from the diffusion number $r = \kappa\,\Delta t / \Delta x^2$ (r), scheme :scheme:

  • "explicit": forward Euler in time (FTCS), stable only for $r \le 1/2$; above, round-off errors in the shortest wave grow by $|1 - 4r|$ per step and take over;
  • "implicit": backward Euler, stable for every r, first order in time;
  • "crank_nicolson": the average of both, stable and second order in time.
source

PDEStudioCore.Examples.solve_heat_2d — Function
solve_heat_2d(params) -> ESimData

The heat equation $u_t = \kappa\,(u_{xx} + u_{yy})$ on the unit square with $u = 0$ on the boundary and $u(x, y, 0) = \sin(\pi x)\sin(\pi y) + \frac12 \sin(2\pi x)\sin(3\pi y)$, N intervals per direction, end time T and the time step from the diffusion number $r = \kappa\,\Delta t / \Delta x^2$ (r), scheme :scheme:

  • "explicit": forward Euler with the five-point Laplacian, stable only for $r \le 1/4$;
  • "adi": Peaceman–Rachford alternating direction implicit: two half steps, each implicit in one direction (tridiagonal solves along the lines), stable for every r and second order.

PDEStudioCore.Examples.solve_poisson_2d — Function
solve_poisson_2d(params) -> ESimData

The Poisson equation $-\Delta u = 2\pi^2 \sin(\pi x)\sin(\pi y)$ on the unit square with $u = 0$ on the boundary (solution $\sin(\pi x)\sin(\pi y)$), five-point Laplacian on N intervals per direction, solved iteratively from $u = 0$ with iterations sweeps of the method :solver:

  • "jacobi": every point from the old values of its neighbours; slow ($\approx N^2$ sweeps per digit);
  • "gauss_seidel": uses the new values as soon as they exist; about twice as fast;
  • "sor": Gauss–Seidel over-relaxed with the optimal $\omega = 2 / (1 + \sin(\pi / N))$; $\approx N$ sweeps.

A stationary problem: the time axis t counts the iterations ($t = k$ after $k$ sweeps), so the plots show the convergence. The error statistics level off at the discretisation error $O(1/N^2)$. (It is called t rather than e.g. :iteration so that frontends that know the axes x, y, z, t, such as PDEStudio, show it as it is.)

PDEStudioCore.Examples.solve_particles_2d — Function
solve_particles_2d(params) -> LSimData

Particles in a solid-body rotation $\dot x = -\omega y$, $\dot y = \omega x$ (one revolution per period): a K×K grid of particles in $[-1, 1]^2$ moved for the time T with the time step dt and the integrator :integrator:

  • "euler": explicit Euler, first order; every step pushes the particles outwards by the factor $\sqrt{1 + (\omega\,\Delta t)^2}$, so they spiral out;
  • "rk2": the midpoint rule, second order (spirals out slowly);
  • "rk4": the classical Runge–Kutta method, fourth order (spirals in, very slowly).

Each particle carries its initial distance from the centre, which the exact flow keeps: the reference is the distance of the particle's current position, so the error statistics measure the radial drift of the integrator. Lagrangian data: in PDEStudio, set_mode!(:lagrangian) first.
